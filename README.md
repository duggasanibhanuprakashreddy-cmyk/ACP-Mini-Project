# 🎨 ACP Mini Project — 2D Graphics Editor in C

A menu-driven 2D Graphics Editor developed in C using a 2D character array as the drawing canvas.

## 📌 Problem Statement

Design and implement a menu-driven 2D Graphics Editor in C using a 2D character array as the drawing canvas.

The canvas is initially filled with `_` (underscore), and graphical objects are drawn using `*` (asterisk).

## 🛠️ Technologies Used

- C Programming
- 2D Arrays
- Functions
- Loops
- Conditional Statements
- Menu-driven Programming

## 🚀 Features

- Menu-driven interface
- 2D character-array based canvas
- Drawing using `*`
- Canvas initialized using `_`
- User interaction through menu options
